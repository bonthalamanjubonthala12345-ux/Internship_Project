# Uber Trip Data Analysis

## Project Overview

This project focuses on analyzing Uber trip data using **Python, SQL, and Microsoft Power BI**. It demonstrates a data analytics workflow, from data cleaning and querying to visualization and dashboard reporting.

The project was completed as part of an **8-week data analytics internship**, with the goal of exploring trip patterns, fare information, passenger counts, and time-based trends.

## Objectives

- Inspect and prepare the Uber trip dataset for analysis.
- Use Python to perform data cleaning and validation.
- Use SQL to query and summarize trip information.
- Analyze trip counts, fare amounts, pickup times, and passenger counts.
- Build an interactive Power BI dashboard to present insights visually.

## Tools and Technologies

- **Python** — Data cleaning and preparation
- **Pandas** — Data manipulation and inspection
- **SQL (MySQL)** — Data querying and aggregation
- **Microsoft Power BI** — Dashboard creation and visualization
- **Jupyter Notebook** — Python development environment

## Project Files

| File | Description |

## Project Workflow

### 1. Data Cleaning with Python

The Python notebook is used for working with the Uber dataset and preparing the data for analysis.

The data preparation stage supports checking data quality and making the dataset suitable for further analysis.

### 2. Data Analysis with SQL

The SQL script creates the `uber_analytics` database and defines a trip table structure. It contains queries for:

- Counting total trips
- Calculating total, average, minimum, and maximum fares
- Analyzing trips by pickup hour
- Comparing trip activity by day of the week
- Summarizing monthly trip and fare information
- Analyzing trips by passenger count
- Identifying the highest-fare trips

### 3. Dashboard Development with Power BI

The Power BI project file (`uber_dashboard.pbix`) contains the dashboard developed for visual analysis of the Uber trip data.

Power BI can be used to present key metrics, charts, and patterns in a format that is easier to understand and explore.

## How to Use This Project

1. Clone or download this repository.
2. Open `Internship_project_Python_cleaning.ipynb` in Jupyter Notebook or JupyterLab.
3. Place the Uber dataset in the appropriate location and update the notebook's file path if necessary.
4. Run the Python notebook to inspect and prepare the data.
5. Open `internship_project_sql.sql` in MySQL Workbench or another compatible MySQL client.
6. Ensure the database and table names match, then import the dataset into the table.
7. Execute the SQL queries to explore trip and fare patterns.
8. Open `uber_dashboard.pbix` in Microsoft Power BI Desktop to view the dashboard.
